## Description

An **autumn eladrin** performer known as Jingles, encountered working at a tavern on the approach to [[Worlds/Astodan/Places/Infinite Mausoleum|Infinite Mausoleum]]. He was apparently restrained by an owner to whom he owed a substantial debt. Party members helped him remove his restraints, and he joined their journey. His **class, subclass, level, debt arrangements and earlier appearances** remain unverified.

## Background & History

Jingles has a history of compulsive service and debts as reported during the tavern encounter. His account is exaggerated and the underlying terms have not been established.

## Personality & Motivations

Jingles is an unpredictable clown and entertainer who seems to want freedom from his debts and constraints. More durable aims remain unknown.

    if (value == null) return [];
    if (Array.isArray(value)) return value;

function resolveFile(value, sourcePath) {
    if (!value) return null;

    const raw = value.path
        ? value.path
        : String(value)
            .replace(/^!?\[\[|\]\]$/g, "")
            .split("|")[0];

    return app.metadataCache.getFirstLinkpathDest(
        raw,
        sourcePath
    );
}

const current = dv.current();

const matchesLink = (value, target) => {
    if (!value) return false;

    if (value.path) {
        const resolved = dv.page(value.path);
        return resolved?.file.path === target.file.path ||
               value.path === target.file.path;
    }

    const name = String(value)
        .replace(/^\[\[/, "")
        .replace(/\]\]$/, "")
        .split("|")[0];

    const resolved = dv.page(name);

    return resolved?.file.path === target.file.path ||
           name === target.file.name ||
           name === target.file.path;
