## Description



An ancient lich seen at the conclusion of the Blood Games. He killed a hydra with *[[The Wanderer's Guide to the Multiverse/Spells/Finger of Death|Finger of Death]]*, possessed a shard important to [[Falatir]], and referred to [[Duke Ingrail]] as a source of corpses. He said he had been confined there for centuries. This does not independently establish his leadership or ownership of the Hallowed Bastion.

- **Session 9 disclosure (not a physical appearance):** Grayson Underwood's patron was identified as **Xerac** ([[Campaigns/Sands of Desolation/Session Journal/Falatir's Sacrifice|Session 9]]). The group did not meet Xerac again during that session, so the prior last-seen metadata is retained. His confirmed **lich** nature supports the newly formalized `Undead` NPC status.

// Normalize arrays, Dataview DataArrays, and single values.
function toArray(value) {
    if (value == null) return [];
    if (Array.isArray(value)) return value;
    if (typeof value.array === "function") return value.array();
    return [value];
}

// Resolve a wikilink or Dataview link to its actual file.
function resolveFile(value, sourcePath) {
    if (!value) return null;

    const raw = value.path
        ? value.path
        : String(value)
            .replace(/^!?\[\[|\]\]$/g, "")
            .split("|")[0];

    return app.metadataCache.getFirstLinkpathDest(
        raw,
        sourcePath
    );
}

const results = [];

for (const quest of quests) {
    const roles = [];

    // Check whether this NPC is the quest giver.
    const giver = resolveFile(
        quest.questGiver,
        quest.file.path
    );

    if (giver?.path === current.file.path) {
        roles.push("Quest Giver");
    }

    // Check general quest involvement.
    const involved = toArray(quest.people).some(value => {
        const file = resolveFile(value, quest.file.path);
        return file?.path === current.file.path;
    });

    if (involved && !roles.includes("Quest Giver")) {
        roles.push("Involved");
    }

    if (roles.length) {
        results.push({
            quest: quest.file.link,
            campaign: quest.campaign ?? "-",
            involvement: roles.join(", "),
            status: quest.status ?? "Unknown"
        });
    }
}

if (results.length) {
    results.sort((a, b) =>
        String(a.campaign).localeCompare(String(b.campaign)) ||
        a.quest.path.localeCompare(b.quest.path)
    );

    dv.table(
        ["Quest", "Campaign", "Involvement", "Status"],
        results.map(r => [
            r.quest,
            r.campaign,
            r.involvement,
            r.status
        ])
    );
}

## Campaign History & Knowledge


- **Session 3 / Session 4 recap:** Appeared after the arena battle and killed an approaching hydra.
- **Session 4:** Made a contract binding Falatir's soul and future service in exchange for a shard. The contract states that the claim passes to a successor if the lich dies; no current successor is known. Released the party after they accepted responsibility for three newcomers. He remained alive when they left.
