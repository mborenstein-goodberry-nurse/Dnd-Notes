## Description
Darian Pageweather is the Keeper of Knowledge in [[Stal'hgite]], where he maintains a library whose interior is magically larger than its exterior. He possesses knowledge of the mysterious artifact sought by the party and has investigated its unusual appearances and movements.

When the party encountered Darian, he appeared bruised and walked with a limp. The circumstances behind these injuries remain unknown.

            incoming.push({
                person: person.file.link,
                type: relation.type ?? "Unknown",
                certainty: relation.certainty ?? "Unknown"

// Search quests across campaigns.
const quests = dv.pages('"Campaigns"')

// Normalize arrays, Dataview DataArrays, and single values.
function toArray(value) {
    if (value == null) return [];
    if (Array.isArray(value)) return value;
    if (typeof value.array === "function") return value.array();
    return [value];
}

// Resolve a wikilink or Dataview link to its actual file.
function resolveFile(value, sourcePath) {
    if (!value) return null;

    const raw = value.path
        ? value.path
        : String(value)
            .replace(/^!?\[\[|\]\]$/g, "")
            .split("|")[0];

    return app.metadataCache.getFirstLinkpathDest(
        raw,
        sourcePath
    );
}

const results = [];

for (const quest of quests) {
    const roles = [];

    // Check whether this NPC is the quest giver.
    const giver = resolveFile(
        quest.questGiver,
        quest.file.path
    );

    if (giver?.path === current.file.path) {
        roles.push("Quest Giver");
    }

    // Check general quest involvement.
    const involved = toArray(quest.people).some(value => {
        const file = resolveFile(value, quest.file.path);
        return file?.path === current.file.path;
    });

    if (involved && !roles.includes("Quest Giver")) {
        roles.push("Involved");
    }

    if (roles.length) {
        results.push({
            quest: quest.file.link,
            campaign: quest.campaign ?? "-",
            involvement: roles.join(", "),
            status: quest.status ?? "Unknown"
        });
    }
}

if (results.length) {
    results.sort((a, b) =>
        String(a.campaign).localeCompare(String(b.campaign)) ||
        a.quest.path.localeCompare(b.quest.path)
    );

    dv.table(
        ["Quest", "Campaign", "Involvement", "Status"],
        results.map(r => [
            r.quest,
            r.campaign,
            r.involvement,
            r.status
        ])
    );
}

const current = dv.current();

const matchesLink = (value, target) => {
    if (!value) return false;

           name === target.file.name ||

## Campaign History & Knowledge
#### Session 1 — [[Leaky Tights to Freaky Fights]]

Darian met the party at his library in [[Stal'hgite]] and shared his research into [[The Stolen Artifact]]. He described reports of the artifact appearing before [[Xurxus]], in a forest, and to a young halfling, before disappearing under unexplained circumstances.

His investigation provided the party with a lead pointing toward [[Goblin Cave]], which they subsequently explored.
