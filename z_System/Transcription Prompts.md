### How to Use: 
The prompt is able to help guide the transcription software. When setting up the workflows, use the basic workflow and the common names that appear in the session to help populate the names. 
Whisper's initial prompt is not a persistent dictionary. Depending on how Buzz processes longer recordings, the prompt may not influence every segment equally.
**Important:** Don't put too many names for the sake of names. 
> [!quote] ChatGPT's Warning 
> Including a name doesn't guarantee Whisper will recognize it correctly. Occasionally, providing too many names can even cause the model to insert names that weren't actually spoken.
