## NEW marker placement rule

Put `<span class="new-tag">new</span>` **immediately after the new name or wiki-linked entity**, before descriptive text, punctuation or parentheticals; for example:

`**Mirage** <span class="new-tag">new</span> — soul-bound construct`

`**Machaimia** <span class="new-tag">new</span> (provisional spelling)`

Do not place the marker at the end of a sentence describing the new encounter. A known returning NPC like **Zoff** should not receive a NEW tag. The dashboard, independently readable scene overview, and first meaningful Log introduction may each display the tag; avoid tagging each repeated name within the same section. Do not tag ordinary mentions of earlier characters as new.
